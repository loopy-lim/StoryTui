## 가정 로그

- 변형 보관 한도 8, 세션 메모리 전용(세이브 미동봉) — 크기·단순함 우선.
- 확률 사이클 값(100/75/50/25)은 ST 통상 프리셋 중심값의 축약 — 텍스트 입력 모달보다
  인지 부하가 낮은 키 순환을 택함.
- **그룹 슬라이스 채택 (설계 위임 판정, 2026-10-23)**: 후보 A(대상 지정+로스터)·B(NPC
  자동 대화 사슬)·C(그룹 턴 커밋) 대조 → **B+A 결합**. 근거: `ParsedAction.target`과
  시스템 프롬프트 화자 명확성 규칙(`이름: "대사"`)이 이미 존재해 A는 엔진 무변경, B는
  사이드 생성 가족(`SideGenerationKind::Scene`)에 정확히 귀속. C는 4개 제출 경로·품질
  게이트·체크포인트 재설계 + 팩 스키마 bump로 1사이클 초과 — KNOWN-LIMITATIONS의 원
  판단 유지, 계속 보류. 장면의 상태 불변(관계 델타 없음)은 플레이어 주권 원칙상
  커밋 턴만 상태를 바꾸는 설계와 일치.
